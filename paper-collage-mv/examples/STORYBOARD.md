# 《只对你有感觉》第五轮 · medium · 分镜

**一句话**：阿栗用一只纸折的「东南西北」去猜小柿的心，猜了一整首歌，最后她打开它——每一格的答案都是他俩。

**画法**：纸艺拼贴，全部 Canvas 2D 代码画。每块纸片无描边，外围 3–5px 不规则白纸边 + 右下淡投影 + 纸纤维颗粒；背景是水彩渐变 + 水渍；全局暗角、胶片颗粒、辉光、光束、光点。

**母题**：东南西北（折纸占卜）。开场它打开，里面是小柿看不透的眼神；主歌里它是转场的「门」；副歌把整张纸摊开成四格世界，「全世界」时四角折起变回东南西北；结尾小柿亲手打开，四格里全是阿栗、正中是他俩。首尾呼应。

**主角**
- 阿栗（男）：栗色乱发 + 锯齿斜刘海 + 后脑两撮翘毛；鼠尾草绿牛角扣大衣带兜帽、衬衫尖领；脸上贴一块创可贴（笨手笨脚的证据）；棕色圆头鞋。
- 小柿（女）：深梅色波波头 + 齐刘海细锯齿；砖红贝雷帽、黄星星发夹；灰粉 A 字外套、奶白大圆领、白袜红鞋。

**色调弧线**：暖奶白（开场）→ 黄昏屋内（主歌一）→ 杏黄午后街（主歌二）→ 副歌四格：糖粉 / 雨蓝转晴黄 / 薰衣草夜灯 / 全景 → 青绿操场 → 晴蓝马路 → 粉紫黄昏屋顶 → 夜蓝星空（结尾）。

## 歌词上屏
默认奶白小纸片宋体字卡，逐字比开唱早 0.22 秒落下，整句结束后向右上飘走。副歌每对「长句 + 短句」：长句在底部，短句用彩色大字卡放进画面里当包袱（都不特别 / 又是晴天 / 就算太远 / 我就收敛 / 就很安全 / 绝不敷衍）。「全世界只对你有感觉」「我只对你有感觉」用红色剪纸大字。

## 分镜
每句歌词都在画面上发生：「食欲不振」他把碗推开，「烦人」她一把抢走、「迷人」她探头一笑，「花挑错颜色」他捧回一把黄花，「我就收敛」秋千停住。东南西北是串起这些句子的线。
