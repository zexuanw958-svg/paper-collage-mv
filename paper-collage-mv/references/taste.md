# 口味与规矩的来历

这些都来自 2026-10-15/16 两首歌（《沉溺》《只对你有感觉》）五轮 MV 和之后十几轮 skill 联调里作者的反馈。改 skill、或者拿不准取舍时读这里。

| 规矩 | 来历 |
|---|---|
| 画风用纸艺拼贴，不用墨线抖动 | 前四轮用工具包默认的粗黑墨线 + boil，作者看了觉得人物质量不如参考片。拆参考片后发现差距在画法体系，第五轮改纸艺，定版 |
| 人物不跟鼓点颠 | 工具包的待机动作锁在 bpm 上，配 DJ 歌（117/152 BPM）时人物一直上下抖，作者一眼就看出来了 |
| 歌词宁早勿晚 | 作者的要求：字幕可以比声音稍微早一点点出来。旧表用 whisper 粗估，有几句早了将近 1 秒，也有晚的；晚的最难受 |
| 运镜单调 | 第四轮开头用 Catmull-Rom 关键帧插值，「停一下」的关键帧夹在快速运动中间，冲过了头，看着一下放大一下缩小，像波浪 |
| 每句都演，但别演成平的情景剧画面 | 第三轮每句歌词配一个情景剧画面，作者觉得不够惊艳。嫌的是画面平（没有尺度反差、没有光、没有一根线串起来），不是画面跟着歌词。这条早先写成了「不要逐句照字面演歌词」，是写错了，见下面「歌词就是剧本」 |
| 一个母题贯穿、首尾呼应、转场丝滑 | 作者指定的舒服参考《把回忆拼好给你》：一个母题贯穿始终，只有两处硬切，其余都是连续运镜和转场 |
| 母题是一条线，不是每个镜头的布景 | 联调第 1 轮（Codex 做《沉溺》）把唱片母题摆在了一半以上的镜头里，中间 15 秒都是同一个「唱片上站两个小人」的构图，画面比定版薄很多。定版的东南西北只在开场、转场和结尾出现，中间是一个个不同的世界 |
| 母题要从这首歌里长出来 | 联调前两轮 Codex 给两首不同的歌都选了「唱片」当母题。这种跟音乐本身挂钩的东西放到哪首歌都成立，等于没找点子。定版的东南西北来自「心像海底针」：猜不透，所以玩猜心的折纸 |
| 「惊艳」的来源 | 参考片的人物其实画得很简单，惊艳靠的是：第一秒就有强图形加揭示、镜头尺度反差大、每段一个有光的世界、一个点子贯穿到底 |
| 表演要密，不能像 PPT | 联调前三轮 Codex 成片，作者的评价是人物动作和动效都比 Claude 做的少得多，整个像一个 PPT。量出来定版每 10 秒 6.1 个人物拍点、最长静止 2.2 秒，前三轮 0.7–3.0 个、最长静止 4.4–20 秒。第 2 轮照搬了木偶骨架也没用，差在编排。所以加了 `act()`、`fx.js` 和 `motioncheck` |
| 给道理，不给数字（防过拟合） | 第 4 轮 skill 写了「每秒至少一个拍点」，Codex 把九段戏的动作都排在同样的 0、0.9、1.8、2.65、3.45 秒上，像节拍器，讲不出一件事。作者不希望 skill 过拟合，要的是把定版好在哪里提炼成做这类视频的设计哲学。所以写了 `philosophy.md`，数字只当报警器 |
| 用整个身体演，构图每段换 | 第 5 轮之后作者指出人物动作单调，只会挥一只胳膊，并要求把构图和世界写透。第 4、5 轮镜头都钉在画面正中只做推拉，十段里八段是两人居中的同一种构图，每帧纸片只有定版一半。所以 philosophy.md 加了「用整个身体演」「构图」「世界要具体、要满」，镜头一节改成「在世界里走」 |
| 道具要一眼认得出 | 第 6 轮之后作者指出好几样东西认不出：围巾、门，还有画面中间一块说不清形状的黄色东西。查下来：围巾是一块弯弯的多边形和一条两头尖的扁条，门是窗户函数立起来歪着转，「一片金色的光」是个黄椭圆。所以 philosophy.md 加了「道具要一眼认得出」，SKILL.md 加了道具关，`fx.js` 加了 `strip` / `tail` / `flap` |
| 转场每次不一样、中途不空 | 第 6 轮几乎每个转场都是同一朵冰花印在平涂底色上，中途小半秒整屏只剩底色，还有残片留在脸上。定版的转场每次都用片里的东西。所以 philosophy.md 加了「转场」一节，`motioncheck` 会报转场中途画面空掉 |
| 换转场要换做法，人物不许淡入 | 第 7 轮两个模型都换了转场用的东西，却没换做法：sol 七次都是道具放大盖屏，astra 九次都是形状开孔；astra 还在每次转场后让人物半透明淡入，像鬼影。两个模型的成片都有大半段落是两人一样大并排站。起因之一是 craft.md 写过「转场前后两个画面里的人物不要同时可见」，两个模型都拿遮挡和淡入来躲。所以 philosophy.md 把转场分成几类做法，同一类最多两次，并写清人物进场靠动作；`motioncheck` 加了半透明人物、两人并排、人物都在正中三项 |
| 动作快、停得久 | 第 6 轮每两个姿势之间都慢慢过渡，好几段人物九成以上时间在动，像泡在水里 |
| 动作疏密跟着这首歌，不跟着定版 | 作者提醒注意过拟合。第 3–8 轮都是《沉溺》，所以第 9、10 轮 skill 不动，换一首慢歌（每秒唱 1.8 个字）和一首快歌（4.4 个字）做留出测试。两个模型做出来都是每 10 秒六七个动作，和定版差不多，快歌那支还更少：`motioncheck` 每次打印的「定版 6.1」被当成了目标。所以它不再打印这个数，只说这首歌整体唱得疏还是密，方向反了才提醒 |
| 疏密不设报警线 | 第 11 轮换成毛不易《消愁》（每秒唱 2.2 个字）。v9 只在「歌疏、动作却不比定版少」时报警，线就是定版的 6.1。两个模型都先被报了一次，然后 sol 从 6.9 减到 6.0，astra 从 7.1 减到 5.8 又加回 6.0，都停在线下一点点，sol 回报写「三项检查均无报警」。线本身成了目标，和第 4 轮刷「每秒一个拍点」、第 9、10 轮对齐「定版 6.1」是同一个毛病：看得见的数都会被当成目标。所以 `motioncheck` 不再报这一条，改成每次都列出动作最满、最空的段落让人回看，没有能消掉的提示 |
| 别拿歌词里的名词当母题，别用万能布景 | 同样两轮，两个模型各做各的，点子几乎一样：「优秀」「灿烂」都做成被当勋章的扣子、由修衣阿姨缝回外套，「5:20」「合影」都做成夹着合影的闹钟。三首歌六支片，屋顶六支都有，晾衣绳五支，温室和电车站各四支，跟歌没关系 |
| 推进匹配穿过去，不停在满屏上 | 同样两轮，三支片推进到一整屏月亮、齿轮或洗衣机圆窗，停一秒多；定版推进玫瑰最满时只停约三分之一秒，旁边还看得见折纸的边 |
| 歌词就是剧本 | 作者看完联调十一轮指出：定版的每个画面都在演那一句歌词，看的人很自然就和歌词对上了；Codex 却按整段歌词的意境自己编一个故事，再把故事放进歌里。查下来：定版每一句都有一件事在演它（见 `examples/STORYBOARD.md`「唱的是」一列）；Codex 的分镜表根本没有歌词这一列，《消愁》两支都演「青年遇见童年的自己」，地点跟着歌走，人物做的事是自己编的，唱「一杯敬朝阳」时没人举杯。起因是 skill 里三条叠在一起把它推离了歌词：「不要逐句照字面演歌词」（上一行，写错了）、「演情绪，不演字面」（「唱到海就画海最平」）、「别拿歌词里的名词」（本来只管母题）。所以 philosophy.md 开头加「歌词就是剧本」，原来那节改名「母题要绕一步」并写明只管母题；SKILL.md 加「每一句都要在画面上发生」，分镜表第一列写歌词；`lyricscheck` 给出「每句一帧」的命令，出片前做字卡测试和换句测试。第 12 轮验证：两个 Codex 的分镜第一列都是歌词，每句一帧都对得上 |
| 表情有来由，换了就拿住 | 作者看联调成片指出：定版的人物表情都很合理，Codex 那几支一会哭一会笑，该哭的时候笑、该笑的时候哭。查代码：定版 50 秒的戏里一共写了 32 个表情关键帧（不算人物设定图），每次都跟着一件事（翻开只有问号→困惑，被抢→吃惊，她一笑→心动）；第 11 轮 sol 55 秒写了 98 个，一个人常常一秒一换，「不怕心头有雨眼底有霜」几秒里是困惑→不耐烦→吃惊→困惑→温柔→开心→大笑。所以 philosophy.md 加「表情有来由，换了就拿住」；`motioncheck` 每次都按段列出每个人换过的表情和这段的歌词，不设报警线。第 12 轮验证：表情底色稳住了，不再乱跳 |
| 一大段对不上时先听清唱的是什么 | 第 12 轮的《年轮》DJ 版唱到第 24 秒以后接的是一段英文说唱，不是中文副歌。一支按人声响度把中文副歌硬摆了上去，字幕和唱的完全不是一回事；另一支认出是英文，却把前面听得清的中文也丢了。所以 SKILL.md 和 lyrics.md 加了「一大段都对不上」，`lyrics_timing.py` 加了 `--lang` |
| 色调跟着这首歌走，亮处要真亮 | 第 13 轮三组对照做《沉溺》（一首甜歌）：用了 skill 的 Codex 做工和镜头最好，却灰扑扑的，作者很介意。量下来平均亮度和定版差不多，差在亮部：定版和不用 skill 的 Claude 那支，接近纸白的亮处随处都是，它几乎没有，背景都是掺了灰的中间色。回头看第 9–12 轮，Codex 的成片也大多偏暗。所以 philosophy.md 加「色调跟着这首歌走」，`motioncheck` 在全片或某几段几乎没有亮部时提醒，不给数 |
| Codex 照 skill 做，Claude 放开做 | 第 13 轮同一首歌、同样的材料做了三组：不用 skill 的 Codex 9 分钟交卷，像幻灯片（42 秒里一半以上的时间画面几乎不动，同一间屋子用了 5 次）；同一个 Codex 用 skill，28 分钟，做工和镜头最好；不用 skill、只被告诉「放开手去做」的 Claude，28 分钟，和它打平。所以 SKILL.md 开头写明：这份是给 Codex 这类照着流程做的 Agent 的，Claude 只借脚本和引擎 |
| 给执行的 Agent 少设限制 | 作者的意思是只简单提几句，不要给太多限制，创意放开。所以 SKILL.md 里创意只写几条硬要求 |
| medium 推理档（Claude）；Codex 至少 high | 作者看完 Claude 做的 xhigh / high / medium 六版，觉得中等思考强度最舒服、创意感最足。联调前六轮 Codex 都用 medium，之后定为至少 high，后期都用 xhigh |
| 返修求快、最小改动 | 作者不想每次返修都再等 40 分钟：用尽可能小的改造方案。复制工程，只改局部，用 `--range` 补渲改动的段落 |
| 抖音导出的音频要切尾音，别的歌原样用 | 抖音导出的片段结尾约 3 秒是水印：音乐硬切，接着是静音和「抖音」人声。有一版把表情卡在了水印人声上，只好返工。那两首是从抖音视频里提取的，别人给的歌一般没有，所以脚本只在认出水印特征时才切 |
| 画面全用代码画 | 发布文案写的是「没用一个 AI 绘画模型，是 Opus 写代码画出来的」，这句必须属实 |
| 封面只放歌名 | 不加宣传小字。底图用最有情绪的一帧，通常是结尾 |

定版成片：《只对你有感觉》第五轮 medium（50.40 秒）。创意是一只纸折的东南西北，从开场贯穿到结尾：她最后打开它，每一格里都是他俩。
