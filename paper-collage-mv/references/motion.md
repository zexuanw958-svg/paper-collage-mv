# 表演怎么落到代码上

道理在 `philosophy.md`。这里讲两件事：定版开场那段戏是怎么从「一件事」落成几十个关键帧的，以及常用的动作写法。定版是一首甜歌，它的密度和具体动作只能当手感参考，换一首歌要从那首歌自己的戏出发。

## 定版开场：一件事，拆成一串动作

先是这段戏用动词讲出来的样子（STORYBOARD 里写到这个程度就够了）：

> 他捧着东南西北想猜她的心，翻开只有一个问号。他泄气，侧过身把碗推开，又不死心翻了一次，还是问号。她从窗外冒出来，一把抢走，他吓一跳。她举过头顶开合两下逗他，歪头笑；他心动。她把它递过来，打开一格，是一朵玫瑰。镜头钻进那一格。

写代码时，再把每个动词落到时间上。下面是 `examples/scenes/s1_room.js` 里 `SC.room` 实际的时间（2.85–10.45 秒）：

| 时间 | 谁 | 做什么 | 怎么动 |
|---|---|---|---|
| 2.85–3.35 | 他 | 把举过头的东南西北放下来，捧在胸前 | ease |
| 3.0 / 3.4 | 他 | 表情变困惑；头顶冒「?」 | 换表情；弹出 |
| 3.85–4.55 | 他 | 翻开：里面只有问号；又合上 | 快开慢合 |
| 4.5–4.8 | 他 | 侧过身去，表情变失落，眼睛往下看 | ease |
| 4.6–5.5 | 他 | 一根手指把碗推开，碗滑出去 | 手先到，碗后动 |
| 5.7–6.1 | 他 | 低头，身子往下沉一点 | 慢 |
| 5.9–6.8 | 他 | 不死心又翻一次，还是问号 | 快开慢合 |
| 6.42–6.8 | 她 | 从窗外冒出来 | 过冲 |
| 6.8–7.22 | 她 | 探身伸长手，一把抢走，东南西北在空中转一圈 | 抢得快 |
| 7.16 | 他 | 吓一跳：表情变惊讶，头一抖，冒「!」 | 余震 |
| 7.5–7.55 | 他 / 她 | 他转身看她；她两手举过头 | ease |
| 7.7–8.3 | 她 | 在头顶开合两下 | 快 |
| 8.3–9.1 | 她 | 歪头，表情变开心，身边闪光依次亮起 | ease，错开 |
| 8.72–8.85 | 他 | 表情变心动，头顶飘起小心 | 换表情；错开飘 |
| 9.3–9.85 | 她 / 他 | 她温柔地看他，把东西递过来；他伸手指它 | ease |
| 10.15–10.3 | — | 打开一格，是玫瑰；两人表情变大笑、哇 | easeOut |
| 10.45 → | 镜头 | 推进那一格，转进下一段 | camK |

同一时间，窗帘在摆，窗外叶子在晃，云在飘，碗里冒热气。

几点值得看：

- **间隔不匀。** 3–7 秒他一个人泄气，动作慢、中间有停；7.0–7.6 秒抢走、吓一跳、转身、举起挤在一起；8.3–9.3 秒又放慢，留给闪光和小心。节奏是跟着戏的情绪走的。
- **一个动作拆成好几拍。** 「抢走」是她探身、手伸长、抢、东西转一圈、他吓一跳、他转身看，不是一个关键帧。
- **反应各不一样。** 吓一跳用余震加「!」，心动用表情加小心，开心用歪头加闪光。不是每次都「对方 0.3 秒后笑一下」。
- **道具一直在两人之间流动**：他手里、空中、她手里、举在头顶、递回来、打开。

## 常用动作写法

括号里是写法，API 见 `engine.md`「人物与表演」。

- **全身姿势**：先定身体，再定手。`pose: 'startle'`（往后一仰）、`'slump'`（塌下去）、`'peek'`（探出身子）、`'shy'`、`'cheer'`、`'sulk'`（背过身）……一个关键帧摆好整个人，再按需要改一两个参数。
- **过冲**：抬手、探头、冒出来、转身、跳起，到位时冲过一点再回来（`act` 关键帧写 `'back'`，或 `backOut`）。
- **预备**：大动作之前先往反方向一点：跳之前蹲一下（`hop` 自带），伸手之前先往回缩，扔之前往后摆。
- **余震**：被吓到、被撞、东西落地，抖两下再停（`jolt(t, t0)` 加到 `tilt` 或 `lean` 上，或 `spring`）。
- **快出慢停 / 慢起快收**：缩手、躲开、惊讶后退用 `'out'`；蓄力、往下掉用 `'in'`。
- **快一下，停住**：一个动作写两个关键帧，前一个是「上一个姿势保持到这一刻」，后一个是几帧之后到位；到位后再写一个相同的关键帧停住，停多久看情绪。停住时只有呼吸和眨眼。别让每个关键帧都慢慢滑向下一个，那样人物一直在变形，像泡在水里。

  ```js
  [2.15, { pose: 'slump' }], [2.3, { pose: 'startle', face: 'surprised' }, 'out'],   // 0.15 秒吓得往后一仰
  [3.4, { pose: 'startle' }],                                                         // 停住一秒，让人看清
  ```
- **视线**：表情里的 `look` 带着观众看：先看东西，再看对方。
- **道具传递**：`puppet()` 返回两只手的位置，东西在两只手之间插值（`mid(a.handL, b.handR, k)`），再画一只 `hand()` 压在上面，看着像握住。
- **反应符号**：`mark('?' | '!')`、`heartsUp`、`sparkle`、`sweat`、`burst`。符号跟在动作后面出，看清了就收。
- **入场**：东西弹出来（`pop`）、从手里拿出来、从画外飞进来、从地上长出来，不要上一帧没有、下一帧就在那儿。
- **跟随**：头发、挂饰、围巾尾巴比身体晚一点停，单独给它一个慢一拍的关键帧。

`template/src/scenes/example.js` 是一段 6 秒的完整示范：他趴在窗边泄气，她从窗外溜过来敲玻璃，他吓一跳；她举起风车，他探身去够，她藏到背后逗他，他又塌回去；她蹦一下，把风车递进窗。照着它的写法写你自己的戏，别照着它的内容。

```js
const B = act(t, [
  [0,    { pose: 'slump', turn: .2, face: 'sad' }],                      // 趴在窗边泄气
  [2.15, { pose: 'slump' }], [2.35, { pose: 'startle', face: 'surprised' }, 'out'],   // 被敲窗吓得往后一仰
  [3.55, { pose: 'stand' }], [3.95, { pose: 'reach', face: 'wow' }, 'back'],          // 探身去够
  [4.3,  { pose: 'reach' }], [4.55, { pose: 'slump', face: 'annoyed' }, 'out'],       // 没够着，又塌回去
]);
const boy = puppet(BOY, 720, 800, 1.35, { t, ...add(B, { tilt: jolt(t, 2.2, .12) }) });
const A = act(t, [
  [.9,   { x: 2200, pose: 'peek', dir: -1, face: 'grin' }], [1.6, { x: 1180 }, 'back'],  // 偷偷溜过来
  [4.2,  { pose: 'offer', dir: -1, aL: 2.1 }],
  [4.45, { pose: 'stand', dir: -1, aL: .3, armBack: 'L', lean: .07, face: 'grin' }, 'out'],   // 藏到背后
]);
const girl = puppet(GIRL, A.x, 940, 1.6, { t, ...add(A, hop(t, 4.62, 34)) });   // 笑着蹦一下
```

## 报警器的来历

`tools/motioncheck.mjs` 逐帧追踪每块人物纸片相对镜头的位移，数出「拍点」（人物从静到动的次数）和最长的整屏静止。联调前三轮 Codex 成片和定版的对比：

| | 拍点 / 10 秒 | 有大动作的帧 | 最长静止 |
|---|---|---|---|
| 定版 | 6.1 | 49% | 2.2 秒 |
| 联调第 1 轮 | 0.7 | 4% | 20 秒 |
| 联调第 2 轮 | 2.6 | 19% | 5.8 秒 |
| 联调第 3 轮 | 3.0 | 16% | 4.4 秒 |

第 2 轮照搬了定版的木偶骨架，拍点还是只有定版的四成，差在戏，不在骨架。第 4 轮给了「每秒一个拍点」的要求，Codex 就把九段戏都排成 0、0.9、1.8、2.65、3.45 秒一个动作，对方都在 0.25 秒后反应，动作多是「露笑」「抬手响应」。表排得很满，却讲不出一件事。所以这些数只当报警器用，不当要求。

第 5 轮按道理做出了真的小戏，作者又指出两件事：人物「只会单调地挥一只胳膊」，构图几乎都是两个人站在正中。量出来也一样：十段里八段是同一种构图，镜头中心全片没动，有一段除了胳膊什么都没动。所以 `motioncheck` 加了每段的构图和身体部位，`camcheck` 加了「镜头钉在原地」的提醒，`puppet.js` 加了全身姿势。

第 6 轮构图换开了、身体也用上了，但每两个姿势之间都慢慢过渡半秒到一秒，`motioncheck` 报好几段人物九成以上时间都在动，看着像泡在水里。所以 philosophy.md 加了「动作本身要快，停住要久」，上面的写法加了「快一下，停住」。

第 9、10 轮换了两首 skill 没见过的歌，看道理能不能用到别的歌上。动作的疏密没跟着歌走：

| | 每秒唱几个字 | sol 拍点 / 10 秒 | astra 拍点 / 10 秒 |
|---|---|---|---|
| 定版那首（甜歌） | 3.1 | 6.1（定版本身） | |
| 慢歌《像我这样的人》 | 1.8 | 7.2 | 7.0 |
| 快歌《5:20AM》 | 4.4 | 6.0 | 7.2 |

快歌唱得比慢歌密两倍多，动作却一样多。`motioncheck` 原来每次开头都打印「定版 6.1」当手感参考，结果被当成了目标。所以现在它不再打印定版的拍点，只说这首歌整体唱得疏还是密，整首的方向反了才提醒；分段表里列出每段唱了几个字作参考。没有逐段按字数报警，因为副歌常常拖长音，字少，情绪却最满。

第 11 轮（毛不易《消愁》，每秒唱 2.2 个字）验证这一改。报警线就是定版的 6.1，两个模型各被报了一次，都把动作减到 6.0 就停了。报警确实让动作疏了些，但线又成了目标。所以现在疏密这件事完全不报警：分段表之后每次都列出动作最满和最空的两段，提醒回去看那几段是不是想要的样子，在回报里说一句为什么。改完它还在，没有能「过关」的数。
